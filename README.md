# 🌲 The Forgotten Walk

Embark on a relentless journey through shadows. Can you survive the darkness and find your way home? **The Forgotten Walk** is an atmospheric, side-scrolling survival adventure built with modern web technologies.

## 🎮 How to Play

Navigate through a dark, obstacle-filled forest. Avoid hammers, saws, birds, and monsters to reach the safety of your home.

### Controls
| Input | Action |
| :--- | :--- |
| **Mouse Wheel** | Scroll down to move right, scroll up to move left |
| **Arrow Keys** | `←` `→` to walk, `↑` to jump |
| **Space Bar** | Jump |
| **Touch (Mobile)** | Swipe left/right to walk, swipe up to jump |

## ✨ Key Features

*   **Parallax Depth**: Multilayered background trees move at different speeds, creating a rich sense of environmental depth.
*   **High-Frequency Collision Engine**: Collision detection runs at 60fps for pixel-perfect survival mechanics.
*   **Smooth Movement**: Custom input handling ensures buttery-smooth character movement with zero delay.
*   **Atmospheric Shadows**: Dynamic silhouette effects that invert your character's colors when walking behind dense foliage.
*   **Timer & High Score**: Track your survival speed and compete against your personal best.

## 🛠️ Tech Stack

*   **HTML5** for game structure
*   **CSS3** for animations and atmospheric styling
*   **jQuery** for DOM-based game logic and input handling
*   **Bootstrap 5** for responsive UI layouts
